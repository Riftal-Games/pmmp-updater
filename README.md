# riftal-protocol

The Bedrock protocol pipeline for the RiftalGames server. pmmp-core builds against the packages in `packages/`; everything else here produces the next version of them.

Start with `CLAUDE.md`, then `/protocol-update`.

| Skill | Use |
|---|---|
| `/protocol-update` | The whole update, from a Mojang preview to a merged, verified core build |
| `/client-scan` | What the installed client says: version, gap, new packets, changed content |
| `/docs-diff` | What Mojang's protocol docs say changed between two versions |
| `/skill-incident` | What every skill does when it fails |
