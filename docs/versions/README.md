# Version runbooks

One file per Bedrock version this repository produced, `<version>.md`, written during `/protocol-update` and finished at its record stage.

Each runbook states: the protocol number, the Mojang docs tags compared, the BDS build used, each stage's start and end time, the downtime from Mojang's release to our merged image, and every incident raised. A stage that ran over its budget names why.

1.26.60 and earlier came from upstream axolotl-pm and have no runbook. 1.26.70 is the first.
